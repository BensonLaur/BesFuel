# 价格数据维护

`data/prices.json` 是数据主文件；`data/prices.js` 是供 `file://` 离线打开的生成副本。HTTP(S) 页面启动后只异步读取本站 JSON，数据采集在站点之外统一执行。

广东来源是[广东省发展和改革委员会业务公告](https://drc.gd.gov.cn/ywgg/)。运行 `powershell -NoProfile -File .\scripts\update-guangdong.ps1` 可读取已生效公告并更新两个文件。脚本验证官网域名、公告标题、92/95/0 号柴油价格、合理价格范围、与现有历史的衔接和输出文件的一致性；任一公告解析失败或同日价格冲突就停止，不用猜测值填空。目前取列表中最近 12 篇，旧历史记录会保留。

其他地区运行 `npm run update:regions`：每个 `scripts/sources/*.cjs` 只读取其声明的官方网站，采集近期已生效公告；共享更新器核对日期、元/升数值、92/95/0 号油号、官方域名及与既存历史的冲突，再原子写入 JSON 和 JS 副本。每个地区独立处理；若某地网站不可达或内容变化，该地区原价、历史及 `checkedAt` 保留，其他地区仍能更新。`npm run check:monitors` 检查只有图片/PDF 的公告是否出现新一期，报告人工复核需求而不改价格。逐页核实的元/升数据记录在 `data/verified/*.json`，可用 `node scripts/import-verified.cjs data/verified/<地区>.json` 显式导入；元/吨记录不能直接进入页面。

`npm run validate:data` 可单独校验本地 JSON 与 JS 副本及每条价格的官方来源域名。GitHub Actions 在 `main` 推送、手动触发和北京时间每天 10:00、20:00 定时执行抓取、校验、测试及 Pages 部署。某地核对失败时保留该地上次可信快照与核对日期；数据校验或测试失败时停止发布。每次成功核对可更新 `checkedAt`，即使价格未变化；同一天无文件变化则不提交新数据。

## 录入原则

1. 优先使用各省发展改革部门公开的成品油价格通知。记录来源 URL、价格执行时间和人工核对日期。
2. `grades[油号].price` 只填有可靠来源的当前参考价；未核实填 `null`。不把其他油号或其他省份的价格推算成官方价。
3. `history` 只追加真实历史记录，格式为 `{ date: "YYYY-MM-DD", price: 8.63, sourceUrl: "https://..." }`。日期是价格生效日，价格单位为元/升。同一日期不要重复录入；确有只提供 HTTP 的政府公告时，必须限定官方网站主机名。
4. `nationalAdjustment.nextAdjustment` 按国家发改委“每 10 个工作日一次”规则及国务院放假调休安排，从最近公告日推算。当前结果为 **预计 2026-10-15 24:00**，不表示届时一定调价；记录规则与假期两个来源。超出已有放假日历的年份不推算。
5. `nationalAdjustment.forecast` 是独立第三方的全国趋势估算，不是广东官方每升价格。当前读取团友网的计算日、周期工作日、方向及元/升估算，同时核对原文和下次窗口；仅保留事实字段与链接。页面仅在预测属于当前窗口且计算日距今不超过两天时展示，过期则隐藏。第三方抓取或解析失败时保留旧字段供追溯，但不阻塞官方核对；新窗口开始时清空旧轮预测。
6. 数据有变化时更新该地区的 `checkedAt`，再检查页面上的价格、历史图和计算结果。不要仅因网页访问成功就声称油价在加油站实时成交。

## 增加地区

在 `regions` 中添加唯一地区键，包含 `name`、`priceScope`、`checkedAt`、`source`、`effectiveLabel` 与 `grades`。`nationalAdjustment` 在快照顶层，只保存内地共用的调价窗口与全国趋势估算；切换地区不改变这一信息，也不将全国约值冒充当地精确每升调幅。页面的地区选择框和价格卡片都读取同一个 `name`，避免两处地名不一致。广东公告覆盖全省，因此名称只写“广东”，适用范围由 `priceScope` 说明。若官方为省内特殊区域单独定价，再单独建键并解释适用范围。增加地区后用共享更新器或人工核验导入器同步生成 JSON 和 JS 副本。

- 截至 2026-09-29 已核对表中四十二个地区或价区的 92、95 号汽油及 0 号柴油价格；其中四十一组数字组合互不相同，河北和天津目前相同。全国总价区数仍待逐地查证。98 号暂不展示数字。

- 站点实付价格可能与省级最高零售价不同，行程计算框允许单独输入。

统一任务定期抓取官方公告并生成经校验的 JSON，网站仅提供这份小型数据文件。用户打开页面时先看内置快照，再异步检查本站文件；网络失败就保留旧值并显示旧核对日期。调价日可以提高检查频率，其他日期每天检查即可。页面的异步 `fetch` 不会阻塞计算，也不需要每个用户浏览器运行 Web Worker 或解析政府网站。全国扩展时，每省独立适配并保留失败隔离。原始公告不属于本站 MIT 代码许可，详见 [使用边界](RIGHTS.md)。
