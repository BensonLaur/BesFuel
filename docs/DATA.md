# 价格数据维护

`data/prices.json` 是数据主文件；`data/prices.js` 是供 `file://` 离线打开的生成副本。HTTP(S) 页面启动后只异步读取本站 JSON，数据采集在站点之外统一执行。

广东来源是[广东省发展和改革委员会业务公告](https://drc.gd.gov.cn/ywgg/)。运行 `powershell -NoProfile -File .\scripts\update-guangdong.ps1` 可读取已生效公告并更新两个文件。脚本验证官网域名、公告标题、92/95/0 号柴油价格、合理价格范围、与现有历史的衔接和输出文件的一致性；任一公告解析失败或同日价格冲突就停止，不用猜测值填空。目前取列表中最近 12 篇已生效调价表及其间更新的不调整公告，旧历史记录会保留；不调整公告不会挤掉用于核价的价格表。

广东采集同时支持“价格调整”和“价格不作调整”（含“不做调整”“不调整”“暂不调整”）标题。不调整公告必须在正文中明确说明本次汽柴油价格不调整，并能核对广东省发展改革委署名及日期；仅有标题、转载链接或正文矛盾均不作为不调整依据。连续多轮不调整时，最新公告和下次窗口推算起点随之更新，价格、原执行时间、价表来源及历史价格节点保持不变。恢复调价后按新价表更新，并替换旧的不调整状态。尚未生效的调价表不提前采用；公告回退、同日冲突、未知公告类型或列表缺少可信价格表时保留旧快照及核对日期，工作流报告核对失败。

地区可选字段 `latestNotice` 为 `{ date, kind, title, sourceUrl }`，日期指公告日，`kind` 为 `adjusted` 或 `unchanged`。它与 `source`（现行价表来源）、`effectiveLabel`（价格开始执行时间）分别记录。页面在价格卡片展示最近官方公告；不调整时明确说明继续执行当前价格，未核价油号及失效折算价格不会因不调整公告变为可用。历史图保留实际价格生效节点，并从最新已核实的不调整公告生成一个空心观察节点，以原价格延伸至该公告日；横轴、日期范围和浮层同步显示公告日期与“不作调整”，统计分别标明价格记录及不调整公告。图表不会把数据核对日期当成调价日期，也不会改写原始价格历史。缺价、缺历史、公告日期无效或超前、折算价格在公告日前失效、价格与历史不一致或存在未核实缺口时，不推导观察节点。旧快照及尚未适配公告类型的地区可以省略该字段，不显示其他地区的结论；目前仅广东采集器自动填充。

其他地区运行 `npm run update:regions`：每个 `scripts/sources/*.cjs` 只读取其声明的官方网站，采集近期已生效公告；共享更新器核对日期、元/升数值、92/95/0 号油号、官方域名及与既存历史的冲突，再原子写入 JSON 和 JS 副本。每个地区独立处理；若某地网站不可达或内容变化，该地区原价、历史及 `checkedAt` 保留，其他地区仍能更新。`npm run check:monitors` 检查只有图片/PDF 的公告是否出现新一期，报告人工复核需求而不改价格。逐页核实的元/升数据记录在 `data/verified/*.json`，可用 `node scripts/import-verified.cjs data/verified/<地区>.json` 显式导入；元/吨记录不能直接进入页面。

`npm run validate:data` 可单独校验本地 JSON 与 JS 副本及每条价格的官方来源域名。GitHub Actions 在 `main` 推送、手动触发和北京时间每天 10:00、20:00 定时执行抓取、校验、测试及 Pages 部署。某地核对失败时保留该地上次可信快照与核对日期；数据校验或测试失败时停止发布。每次成功核对可更新 `checkedAt`，即使价格未变化；同一天无文件变化则不提交新数据。

## 原油趋势参考

原油数据独立保存在 `data/crude-prices.json`，离线副本为 `data/crude-prices.js`。`npm run update:crude` 每次按 Eastmoney → Yahoo Finance → Sina Finance 自动选择来源，每个来源必须同时取得两条有效曲线，主源恢复后优先使用主源。东方财富 `102.CL00Y`、`112.B00Y` 为连续期货参考，Yahoo `CL=F`、`BZ=F` 为 NYMEX 期货参考，新浪 `CL`、`OIL` 为 CFD 差价合约参考，均为美元/桶。三个来源保留最近最多 200 条日线；不将它们当成同一合约、交易所官方结算价、现货价或国内调价预测。`.github/workflows/pages.yml` 在现有每天两次定时任务中统一采集、提交和打包；`usage: third-party-reference` 标识第三方参考数据，校验器兼容旧的 `local-preview` 快照。

采集器校验固定品种和市场、响应状态、日期顺序、开高低收关系、价格范围及新旧历史一致性；拒绝未来日期、过旧响应、记录回退及未复核的已完成历史修订。纽约当地日期在 18:00 前保持当日日线为未完成状态，交易日之后才视为已完成；由 `Intl` 处理夏令时。不因北京时间已跨日就认定美国交易日结束，也不因浏览器时间推进而自动把旧盘中快照升级成收盘价。来源成功重新采集后，才可晋级该日记录。

同一来源的两个请求并行执行，但任一品种失败就拒绝该来源整批数据，并尝试下一来源；不会更新一条、保留另一条。候选至少有 90 条已完成历史，最新参考日期不得比当前快照回退，也不得超过四个自然日未更新。全部失败时保留价格、行情日期、各品种 `fetchedAt` 和顶层 `updatedAt`，仅写入 `collection` 检查失败状态，并以非零退出码报告；首次采集全部失败时不生成文件。通过备用源成功更新退出码为零，失败尝试保留在日志和状态中。运行 `npm run validate:crude` 校验 JSON、JS 副本；访客只读取本站文件，不直接请求第三方行情。

顶层可选 `collection` 保存采集模式、检查时间、尝试顺序、实际来源、更新/保留结果及本次切换前来源。它与报价更新时间分开校验，失败检查不会把旧价格标成新数据。页面显示切换、备用来源或更新失败提示，拒绝用更旧的检查结果覆盖新状态。`--check` 不改文件，`--source=eastmoney/yahoo/sina` 只为本次手动指定来源；下次不指定来源时重新自动排序，详见 [来源与切换步骤](CRUDE_SOURCES.md)。

Actions 使用 `npm run update:crude:ci`：正常更新或全部来源失败但旧快照仍校验通过时，继续生成站点；后一种情况在工作流发出警告，并发布保留的快照和失败状态。快照损坏、JSON/JS 不一致、写入失败、数据校验或测试失败则阻断发布。`npm run build` 生成并校验 `public/`，浏览器检查直接针对该产物，随后提交同一批数据并部署；网页脚本、原油模型、两套 JSON/JS 数据和原始支持图片均包含在产物中。

Yahoo 校验品种、NYMEX 市场、期货类型、美元单位、纽约时区、日频和 OHLC 数值。历史记录一般使用纽约午夜时间，最新记录可能使用实际报价时间；纽约 18:00 后的记录归入下一交易日，拒绝周末交易日，并用 `Intl` 处理夏令时。二进制浮点价格规范到美分，不使用复权收盘字段代替期货参考价。全空价格记录跳过，部分缺失或异常记录拒绝。新浪 JSONP 仅按 JSON 解析，不执行脚本；其部分开盘价在高低范围外，因此仅用收盘参考字段并验证其范围，不提供 OHLC 蜡烛图。新浪品种由固定请求 URL 指定。继续使用同一来源时，已完成历史修订仍拒绝静默覆盖。

## 录入原则

1. 优先使用各省发展改革部门公开的成品油价格通知。记录来源 URL、价格执行时间和人工核对日期。
2. `grades[油号].price` 只填有可靠来源的当前参考价；未核实填 `null`。不把其他油号或其他省份的价格推算成官方价。
3. `history` 只追加真实历史记录，格式为 `{ date: "YYYY-MM-DD", price: 8.63, sourceUrl: "https://..." }`。日期是价格生效日，价格单位为元/升。同一日期不要重复录入；确有只提供 HTTP 的政府公告时，必须限定官方网站主机名。
4. `nationalAdjustment.nextAdjustment` 按国家发改委“每 10 个工作日一次”规则及国务院放假调休安排，从最近已核实公告日（含不调整公告）推算，不表示届时一定调价；记录规则与假期两个来源。超出已有放假日历的年份不推算。
5. `nationalAdjustment.forecast` 是独立第三方的全国趋势估算，不是广东官方每升价格。当前读取团友网的计算日、周期工作日、方向及元/升估算，同时核对原文和下次窗口；仅保留事实字段与链接。页面在预测属于当前窗口时展示；计算日距今超过两个自然日后，改为“本轮最近估算”，保留数值、计算日期和来源，弱化样式、隐藏涨跌箭头，并提示等待本轮更新、仅作历史参考。来源数据较旧不等同于抓取失败；通过原文核验的本轮旧估算仍可收录，但不能覆盖计算日更新的已有估算，也不能因核对成功而刷新计算日期。第三方抓取或解析失败时保留本轮可信预测，不阻塞官方核对；新窗口开始时清空旧轮预测，页面也会隐藏跨周期或窗口已结束的估算。
6. 数据有变化时更新该地区的 `checkedAt`，再检查页面上的价格、历史图和计算结果。不要仅因网页访问成功就声称油价在加油站实时成交。

## 增加地区

在 `regions` 中添加唯一地区键，包含 `name`、`priceScope`、`checkedAt`、`source`、`effectiveLabel` 与 `grades`。`nationalAdjustment` 在快照顶层，只保存内地共用的调价窗口与全国趋势估算；切换地区不改变这一信息，也不将全国约值冒充当地精确每升调幅。页面的地区选择框和价格卡片都读取同一个 `name`，避免两处地名不一致。广东公告覆盖全省，因此名称只写“广东”，适用范围由 `priceScope` 说明。若官方为省内特殊区域单独定价，再单独建键并解释适用范围。增加地区后用共享更新器或人工核验导入器同步生成 JSON 和 JS 副本。

## 当前数据边界

- 截至 2026-09-29 已核对表中四十二个地区或价区的 92、95 号汽油及 0 号柴油价格；其中四十一组数字组合互不相同，河北和天津目前相同。全国总价区数仍待逐地查证。98 号暂不展示数字。
- 各地历史包含已核对的公告，节点数不一，图上没有示意节点。
- 下一轮窗口按 2026 年官方规则与调休安排推算；2026-09-28 的第三方首日市场估算为全国参考约下调 0.18 元/升，后续会变化。国家发改委可因特殊情形暂停、延迟或缩小调价幅度。
- 站点实付价格可能与省级最高零售价不同，行程计算框允许单独输入。

## 推荐的线上更新方式

统一任务定期抓取官方公告并生成经校验的 JSON，网站仅提供这份小型数据文件。用户打开页面时先看内置快照，再异步检查本站文件；网络失败就保留旧值并显示旧核对日期。调价日可以提高检查频率，其他日期每天检查即可。页面的异步 `fetch` 不会阻塞计算，也不需要每个用户浏览器运行 Web Worker 或解析政府网站。全国扩展时，每省独立适配并保留失败隔离。原始公告不属于本站 MIT 代码许可，详见 [使用边界](RIGHTS.md)。
