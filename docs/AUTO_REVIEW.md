# 地区自动核验与异常提醒

2026-10-23 将能确定解析的官方价格接入自动入库，沿用每天北京时间 10:00、20:00 的 GitHub Actions 发布计划。杭州 FC 继续在 09:45、19:45 采集；GitHub 定时任务可能延迟。无需本机开机，也不需要桌面 Codex 定时执行。

## 自动更新范围

原有 11 个地区采集适配器及广东更新器之外，本次增加 10 个地区或价区的自动核价，合计 22 个地区或价区具备自动更新路径：

- 海南、江西：发布端自动发现省发改委最新公告，校验发布来源、时间、最高零售元/升列、油号及数值；海南还核对汽油车辆通行附加费口径。江西使用 Windows curl 的系统 TLS，证书验证保持开启，重定向仍逐跳检查官方域名。
- 安徽、重庆、河南、宁夏、山东、克拉玛依主价区、独山子：复用 FC 已严格解析的完整三油号价格，在发布端再次核对日期、历史和官网白名单，自动入库。不是把所有监测器的待复核标志统一关闭。
- 湖南：校验公告所属 XLS，按单元格的两位小数显示格式读取零售元/升列，独立检查表内全省范围和生效日。只读取官方工作簿已有数值，不计算公式，不用吨价推算。XLS 读取依赖固定为 `xlrd==2.0.2`，安装时核对 PyPI wheel SHA256。

发布端使用当前 FC 格式及校验摘要，新增逻辑不修改 FC 的来源适配器或摘要；不需要重新部署函数包。每轮核验报告保存为 Actions 的 `automatic-review` artifact，保留 14 天；价格和历史仍提交进仓库。

## 保留与拦截

- 来源失败时保留该地区旧价格及旧核对日期，其他通过的地区可以更新。
- 非官方链接、单位或表头改变、缺油号、同日价格冲突、生效日期超前等情况拒绝写入。
- 只提供最新一条记录的监测项目，如果检查中断超过三天且出现其间的新调价，会要求先补历史，避免将遗漏期间画成价格不变。海南、江西会读取首页仍列出的多期公告。
- 图片价表、尚未支持的 PDF、辽宁和新疆其余地区的升价依据、青海具体地域归属及西安历史缺口，仍不能靠运行成功就宣称已核实。
- 黑龙江现有系数在 2026-10-31 到期。未取得并核实新季系数时，11-01 起隐藏失效升价并产生新的复核提醒。尚未实现自动发现及导入新季系数。
- 98 号是企业自主定价，不生成省级统一价格。用户仍可输入实际加油价。

## 提醒规则

提醒采用本仓库 GitHub Issue，并提及仓库所有者；通知渠道由用户的 GitHub 通知设置决定。没有新增异常时不发送例行消息。

- 网络、TLS、DNS、HTTP 错误连续三个不同发布运行仍相同，才创建提醒；不因一次临时波动通知。
- 新公告无法解析、价格冲突、季节系数失效等数据问题立即提醒。
- 以地区、异常类别和官方依据生成指纹。同一异常不重复开 Issue；新的异常依据出现时关闭旧记录并创建新记录，恢复后自动关闭。
- 已经告知用户的辽宁旧吨价缺口作为初始基线，不再次通知；出现新公告时会形成新指纹。
- 写入提醒成功后才保存去重状态；API 写入后重试也会按远端指纹检查，避免重复提醒。提醒失败会让运行报告失败，不静默宣称已通知。

工作流给发布作业增加 `issues: write`，只用于上述异常记录；不扩大阿里云只读角色权限。流程自身失败仍沿用 GitHub 原有的运行失败通知。

## 验证入口

`npm test` 包含官方 HTML 摘录、自动入库的日期/单位/冲突/回退测试，以及异常等待、去重、恢复和重试测试。`python -m unittest discover -s tests -p '*_test.py'` 校验湖南 XLS 的列语义、显示精度及生效时间。人工核验时另用四期真实 XLS 对照价格。

线上验收须确认海南、江西及湖南读取成功、自动核价报告无新增错误、构建和浏览器检查通过，并核对 Pages 文件。以上自动更新能力不等于全部 45 个地区均已支持自动解析。
