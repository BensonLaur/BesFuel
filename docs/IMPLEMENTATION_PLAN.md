# BesFuel 实施方案

更新时间：2026-09-28。本文记录首个广东公开版及逐地区扩展的实现边界。

## 产品范围

首页回答四件事：当前地区与常用油号的已生效参考价、下一轮调价窗口及有来源的涨跌预估、历史价格趋势、此次行程每公里与总油费。地区名称只保留一个 `name` 字段，右上角选择框与价格卡片同步显示；价格适用范围另由 `priceScope` 解释。

## 已完成

- 手机优先的单页界面，油号切换联动价格、历史图和油费计算；常用油号与油耗保存在本地浏览器。
- 已接入二十五个地区或价区，使用各地发展改革部门公布的最高零售价或按官方吨升规则折算；98 号维持缺价状态。地区名单、历史长度和更新方式见 [数据维护说明](DATA.md)。
- 广东公告更新脚本和独立地区采集器会校验官网域名、标题、价格表、日期及数值，并生成带来源的 JSON 和浏览器脚本。图片/PDF 公告由人工逐期核价，监测器提示新公告；监测确认公告未变且折算系数仍有效时，更新该地区核对日期。
- HTTP(S) 页面先显示内置快照，再异步读取本站 JSON。失败时继续显示旧数据；刷新不会覆盖用户手动输入的加油站价格。
- 广东下一轮窗口按国家调价规则和 2026 年调休安排推算；全国市场估算单独读取第三方，附计算日、工作日和原文链接，超过两天或切换调价周期后隐藏。
- 全国共用的窗口与市场估算在顶层 `nationalAdjustment`；地区只保存当地已生效价格和历史。预测用 ↑／↓ 说明方向，仍注明全国参考。
- 计算测试和浏览器交互检查可通过 `npm test` 与 `npm run smoke` 执行。

## GitHub Pages 发布阶段

1. 代码和文档采用 **MIT**；收款图片、政府公告与其他第三方数据的边界见 [使用边界](RIGHTS.md)。
2. Pages 来源为 GitHub Actions。`main` 推送、`workflow_dispatch` 和北京时间每天 10:00、20:00 的 `schedule` 都运行 `.github/workflows/pages.yml`；GitHub 定时任务可能延迟，不能承诺分钟级更新。
3. Windows runner 依次抓取广东和各独立地区官网，校验域名、标题、全部必需油号、元/升单位、价格范围、历史衔接、JSON/JS 一致性，随后运行单元测试和 Edge 浏览器检查。单个来源失败时该地旧价与原核对日期保留；整体数据校验或测试失败时停止发布。
4. 数据有变化时，任务在验证后提交快照，并在**同一次工作流**中上传静态站点产物、部署 Pages。没有变化时不生成新的数据提交。发布产物只包含页面所需的 HTML、CSS、JS、JSON 与两张收款原图。
5. 页面继续只请求本站的 `data/prices.json`。访客浏览器无需直接访问或解析政府公告。

后续可在调价窗口附近评估检查频率；每次数据提交和部署记录在 GitHub Actions 中可查。

## 数据扩展阶段

- 逐省增加独立的官方公告适配器，以官方定价区域为选择单位；省内有单独标准时按价区分别核对。每条历史节点保存价格、生效日和公告链接。用户优先看到已核实当前价，历史在同一来源逐步补齐。
- 国家层面的每吨调价信息与省级每升最高销售价分别存储；不能用全国调价金额直接替代用户所在地区的每升价格。
- 下次调价窗口需有可核实的规则与调休来源，并标注“预计”。涨跌幅属于全国市场估算，必须单独记录来源、生成时间和有效期；过期就显示缺失状态，广东正式价格仍以省级公告为准。
- 若引入第三方数据服务，先核对授权、更新频率、稳定性和历史数据权利；加油站实付价不能与省级最高价混称。

## 自愿支持入口

打赏入口使用与油费主题呼应的文案 **「⛽ 给 BesFuel 加点油」**，放在行程计算结果卡片末尾。它是用户主动点击的轻量入口，不在打开页面或计算完成时自动弹出，也不遮挡价格、调价信息和计算结果。

点击后打开底部卡片：先用短暂的油表上升动画表达“补给”，再显示“自愿支持开发与维护”的说明，以及微信、支付宝两个切换项。动画只对打开卡片作出反馈，不表示有人付款或打赏进度。收款金额由用户在支付应用内决定；“加点油”只是趣味表达，不把一升油价格或本次行程油费写成实际付款金额。关闭卡片后立即回到原页面和原计算结果，不建立订单、不检测付款、不解锁功能。

两张原图从 Besktop 的 `resources/support/wechat.png` 与 `resources/support/alipay.png` 逐字节复制到 BesFuel 自有静态资源。可见收款主体为微信 `Benson(**城)`、支付宝 `Bes软件`；作者已允许 BesFuel 公开展示。图片完整等比显示，不裁切二维码、留白、平台标识或收款主体，也不重绘二维码。桌面端提示用手机扫码；手机端提供保存原图和在微信或支付宝相册识别的说明，并允许点开原图查看。

代码使用 MIT；收款图片单独说明归属和使用范围，不将它们默认视为 MIT 授权素材。浏览器自动化覆盖窄屏、桌面、切换和关闭行为；仍需分别用真实手机确认两张码能识别、收款人正确。

## 验收标准

- 新公告已生效后，更新任务能正确改变对应油号的价格、历史图与默认行程成本。
- 公告页面结构改变、缺少油号或价格越界时，旧数据不会被错误覆盖。
- 切换地区时，右上角与价格卡片显示同一名称，相关价格、趋势和计算结果同步变化。
- 页面和数据源都标明来源与核对日期；断网、本站 JSON 失败、缺失 98 号或缺少预测时仍可使用手动油价计算。
- 自愿支持卡片只在点击后出现，二维码原图清晰可用；未打赏的用户仍能完整使用全部免费功能。
