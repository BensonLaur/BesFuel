## 自愿支持收款图片

`resources/support/wechat.png` 与 `resources/support/alipay.png` 是作者提供的原始收款图片。作者已允许将两张原图用于 BesFuel 的公开仓库和 GitHub Pages 页面；此许可只覆盖在 BesFuel 中展示，不能推定第三方有权复制后用于自己的收款页面。图片与 Besktop 原件逐字节一致，未裁剪、改写二维码或更换收款主体。

图片可见的收款主体分别为微信 `Benson(**城)`、支付宝 `Bes软件`。BesFuel 页面不建立订单、不检测付款、不表示付款成功。付款前，使用者仍应在支付应用中确认实际收款人；发布后还需作者用真实手机分别核验两张码的识别和收款主体。

## 政府公告与价格记录

`data/prices.json` 和 `data/prices.js` 汇集广东省发展和改革委员会公开公告中的价格、执行日期及来源链接。公告正文、表格、网页设计与其他原始内容由原发布方管理，不属于 BesFuel 的 MIT 代码许可。本站仅保留提供参考价所需的事实字段和逐条来源；引用或再利用原公告时应核对原站说明与适用要求，不把本站快照当成官方实时服务。

本站引用团友网公开发布的单次市场估算数值、计算日期和原文链接，不复制其文章、图表或网站素材；该预测及其来源页面不适用 BesFuel 的 MIT 许可。预测仅供全国趋势参考，可能随行情或调控改变，不是广东省官方调价结果。将来加入其他地区公告、市场预测、地图或第三方数据服务，仍须分别核对来源、使用条件、更新时效与再发布权限。当前没有已核实的全国每升官方油价或广东 98 号价格。
