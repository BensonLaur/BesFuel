# BesFuel · 油价随行

面向国内燃油车主的单页看板：查看所在地区与常用油号的参考油价、下一轮调价信息、历史价格，并计算每公里与本次行程的油费。

## 本地使用

直接双击 `index.html`，无需安装依赖或启动服务。页面不加载外部脚本、字体或图片；离线时也能计算油费。油号和常用百公里油耗保存在浏览器本地。若通过 HTTP(S) 托管，页面先显示内置快照，再异步读取本站的 `data/prices.json`，有更新就刷新报价和趋势；每位访问者都不会直接抓取政府网站。

目前数据只收录广东省官方公布的 92、95 号汽油和 0 号柴油价格。公告给出广东全省的最高销售价格，没有区分广州与省内其他城市；加油站实付价可能不同。98 号和其他省份仍未核实。下次调价窗口按官方工作日规则与放假安排推算；市场涨跌估算来自独立第三方，均与已生效官方价格分开显示。超过核对期限时，页面会提示核对来源。

公开页面：[BesFuel GitHub Pages](https://bensonlaur.github.io/BesFuel/)；源码：[BensonLaur/BesFuel](https://github.com/BensonLaur/BesFuel)。

## 已实现

- 手机优先的单页界面，选择油号后联动价格、历史记录与行程计算。
- 输入本次里程、百公里油耗和每升价格，立即显示每公里成本与总油费。
- 默认采用已收录参考价，也可改用加油站实际成交价。
- 用广东省发改委历次公告生成真实阶梯趋势图，目前已收录 12 次调价记录；浅色横虚线标出最新价，悬停、轻点或键盘聚焦节点可查看完整生效日期与价格。
- 将已生效价格、推算的下一调价窗口和第三方市场估算分开呈现；预测附计算日、周期工作日及原文链接，过期后自动隐藏。
- 行程结果后有「⛽ 给 BesFuel 加点油」自愿支持入口；仅在点击后显示微信、支付宝原始收款图片。手机可保存原图并在相应应用中从相册识别，所有功能始终免费。

数据权利与收款图片使用范围见 [使用边界](docs/RIGHTS.md)。当前能力与 GitHub Pages 发布流程见 [实施方案](docs/IMPLEMENTATION_PLAN.md)。

更新广东数据：

```powershell
powershell -NoProfile -File .\scripts\update-guangdong.ps1
```

脚本读取官网公告列表和最新 12 篇已生效通知，核对标题、价格表、历史衔接及 JSON/JS 一致性后才写入 `data/prices.json` 和浏览器用的 `data/prices.js`。它还按 [调价规则](https://www.ndrc.gov.cn/xxgk/zcfb/tz/201601/W020190905506573420251.pdf)和 [2026 年放假安排](https://www.beijing.gov.cn/cs/gncs/zcwj/202603/t20260327_4568275.html)推算下次窗口，并尝试读取 [团友网的市场估算](https://www.tuanyou.net/youjia/)。市场估算不是官方价格：首个接入快照（2026-09-28，第 1 个工作日）为全国参考约下调 0.18 元/升，后续可能反转或因政策调控改变。估算读取失败不影响官方价格核对；页面会隐藏超过两天或与当前窗口不符的预测。官网无法访问、公告结构变化、价格不完整或历史冲突时会报错并保留现有数据。

GitHub Actions 在 `main` 推送、手动触发和北京时间每天 10:00、20:00 定时运行同一任务：更新并验证数据、运行测试、仅在快照变化时提交数据，然后从本次运行直接部署 Pages。定时任务可能延迟；官方核对失败时不部署新版本，已发布快照及核对日期继续保留。访客浏览器只请求本站 JSON，不访问政府或市场网站。

## 计算方式

```text
每公里油费 = 百公里油耗 × 每升油价 ÷ 100
本次总油费 = 每公里油费 × 本次里程
```

估算仅包括燃油费，不包括停车、过路费和车辆折旧。

## 项目结构

```text
BesFuel/
├─ index.html           页面结构
├─ styles.css           响应式样式
├─ app.js               页面交互与历史图
├─ lib/calc.js          计算与输入校验
├─ data/prices.json     带来源的价格快照
├─ data/prices.js       浏览器可直接打开的生成副本
├─ resources/support/   原始微信、支付宝收款图片
├─ scripts/             官方公告更新及数据校验脚本
├─ docs/DATA.md         数据维护约定
├─ docs/RIGHTS.md       代码、图片和第三方数据边界
├─ .github/workflows/   定时核对和 Pages 发布
└─ tests/calc.test.cjs  计算逻辑验证
```

运行 `npm test` 可验证计算和数据边界；`npm run test:updater` 验证残缺公告不会覆盖旧快照；`npm run validate:data` 校验价格文件；`npm run smoke` 用本机 Edge 验证手机、桌面与浏览器交互。无第三方包依赖。可设 `BESFUEL_DEPLOY_URL` 后运行 `npm run smoke` 检查已部署页面。
